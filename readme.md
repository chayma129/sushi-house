# 🍣 Sushi House – Site Web

## 1. Présentation du projet
Sushi House est un site web d'un restaurant japonais spécialisé dans la préparation et la vente de sushis.

Ce projet a été réalisé dans le cadre d'un atelier de développement web.

## 2. Objectifs du projet
- Créer un site web simple et attractif.
- Présenter le restaurant et ses produits.
- Afficher les prix des différents menus.
- Permettre aux clients de réserver une table.

## 3. Technologies utilisées
- **HTML5** : structure des pages web.
- **CSS3** : mise en forme et design.
- **JavaScript** : validation des formulaires.

## 4. Fonctionnalités
- Page d'accueil.
- Page des prix.
- Page de réservation.
- Validation des champs du formulaire.
- Vérification de l'adresse e-mail.
- Vérification du numéro de téléphone (8 chiffres).
- Changement de couleur des champs :
  - Rouge : champ invalide.
  - Vert : champ valide.
